# Campus Intelligence prototypes

Four clickable prototypes made for the **Campus Intelligence Challenge** at Dutch Innovation Park, Zoetermeer (school project, De Haagse Hogeschool). The prototypes themselves are in Dutch.

| # | Prototype | Live |
|---|-----------|------|
| 1 | Gespreksbriefing | [open](https://jessyroest.github.io/campus-intelligence-prototypes/p1-gespreksbriefing/) |
| 2 | Matchbriefing | [open](https://jessyroest.github.io/campus-intelligence-prototypes/p2-matchbriefing/) |
| 3 | Verteltrainer | [open](https://jessyroest.github.io/campus-intelligence-prototypes/p3-verteltrainer/) |
| 4 | Rekentool | [open](https://jessyroest.github.io/campus-intelligence-prototypes/p4-rekentool/) |

Each prototype is a single self-contained `index.html`, served with GitHub Pages.
